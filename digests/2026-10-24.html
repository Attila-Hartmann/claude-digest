Introducing Claude Duet

Claude (Official) • October 22, 2026

Anthropic's official launch video introduces Claude Duet, a proactive personal AI agent built on Opus 5.5 that works for you around the clock. Claude Duet sends a concise morning brief each day highlighting urgent items from your connected apps, then checks those apps every few hours and alerts you when something needs attention. The agent can handle tasks like scheduling meetings, building dashboards, and drafting financial forecasts entirely autonomously — but always asks for approval before taking consequential actions like sending a message, making a payment, or deleting a file. Claude Code's Agent Teams Are Insane - Multiple AI Agents Coding Together in Real Time

Cole Medin • February 2026

Popular AI builder Cole Medin demos Claude Code's experimental Agent Teams feature, which lets multiple Claude Code instances collaborate on a single codebase in parallel rather than working sequentially. One session acts as the team lead — it creates the team, spawns teammates, assigns tasks, and synthesises results — while peer agents can claim tasks from a shared queue and message each other directly with discoveries mid-work. Teammates can run in-process or in split panes (via tmux or iTerm2), and the video shows four agents simultaneously performing a multi-faceted code review covering security, performance, and test coverage. The feature is enabled via the CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS environment variable and is marked experimental, making this an early look at what Medin calls a genuinely game-changing approach to large-scale AI-assisted development.

How to Use Multi-Agent Workflows in Claude Code: Skills, Subagents & Handoffs (2026)

The Code City • 2026

A practical tutorial walking through how to build production-ready multi-agent pipelines in Claude Code using three key primitives: Skills (reusable packaged instructions), Subagents (isolated Claude Code instances with their own context window and tool access), and Handoffs (structured mechanisms for passing state between agents). The video explains how an orchestrator agent plans work and routes tasks to specialist agents, using structured JSON outputs as the communication contract between them. It also covers the Claude Code v2.1.154 Dynamic Workflows feature — a research preview that lets Claude generate a JavaScript script to fan out work across up to 16 agents simultaneously, delivering significant throughput gains for large coding tasks. Best practices include writing error fields to state on failure (rather than crashing silently) and designing each skill to be narrowly scoped so the orchestrator can compose them flexibly.
