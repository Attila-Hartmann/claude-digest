Introducing Claude Dashboards and Claude Motion

Claude (Official) • N/A views • October 8, 2026

Anthropic launched two new beta features on October 8, 2026: Claude Dashboards and Claude Motion. Dashboards lets users connect data sources like BigQuery, Snowflake, Databricks, and Salesforce, then generate auto-updating live dashboards through natural-language prompts — no manual chart building or BI tool required. Claude Motion generates short animated explainer videos from text, rendered as fully editable code and exportable as MP4, using no AI video generation model, so there are no AI-generated people or invented footage. Dashboards is available to paid plan users while Motion requires Team or Enterprise; on the same day, Docs, Slides, and Design graduated from beta and became available to all plans including free.
