Introducing Claude Duet

Claude (Official) • 1,186,208 views • October 21, 2026

Anthropic officially launched Claude Duet, a standalone proactive AI agent app that contacts you rather than waiting to be asked. Powered by Claude Opus, Duet monitors your connected calendar, email, and documents, sends you notifications when something needs attention, and keeps working in the background after you put your phone down. #3

Mods in Claude Code: change how Claude Code works

Claude (Official) • 490,391 views • October 5, 2026

Anthropic introduced Mods, small TypeScript event handlers that let you customize Claude Code's behavior from the inside. Mods can intercept prompts before they reach the model, block or transform tool calls, inject context from external systems, and add entirely new rendered UI panels to the Claude Code interface. The feature requires Claude Code 2.1.287 or later and marks the first time Claude Code is truly programmable. The video demonstrates building a mod that automatically appends coding-style guidelines to every prompt, another that blocks dangerous shell commands, and a third that adds a real-time token-usage meter to the sidebar.
