#3

Introducing Agent View in Claude Code

Anthropic (Official) • N/A views • May 12, 2026

The official Anthropic announcement video for Agent View, a major new addition in Claude Code 2.1 released in May 2026. Agent View provides a single dashboard screen for managing multiple parallel Claude Code sessions, replacing the need to juggle terminal tabs or tmux panes. Each row in the view shows a session’s live status — working, waiting for input, completed, or failed — and developers can send sessions to the background with /bg, peek at progress with the spacebar, or reply to a session inline without switching to a full transcript. The feature also introduces the /goal command, which keeps Claude working autonomously across multiple turns until a specified completion condition is met. Available now as a Research Preview on Pro, Max, Team, Enterprise, and Claude API plans.
